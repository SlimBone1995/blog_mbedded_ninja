## This repository

This repository contains an **unofficial Simplified Chinese translation** of
blog.mbedded.ninja. The translation is a derivative work. Changes made:

- Prose, headings, table text, image captions and footnotes have been
  translated into Simplified Chinese.
- Some terminology includes the original English term in parentheses on first
  use, to make technical terms easier to verify.
- Text inside diagrams and screenshots generally remains in English; the
  diagrams themselves have not been redrawn.
- Page layout and code samples are otherwise kept identical to the source.

The Chinese translation is distributed under the same license,
**CC BY 4.0**. When reusing it, please attribute both the original author and
this translation, link to the license, and indicate that changes were made.
