SMA 是一种 2 引脚 SMD 元件封装，常用于二极管。SMA 封装的另一个常用名称是 DO-214AC。SMA 是 SMA、SMB 和 SMC 系列中尺寸最小的封装。

<Image src={import('./_assets/sma-do-214ac-component-package-3d-render.jpg')} width="200px">SMA（DO-214AC）元件封装的三维渲染图。</Image>

注意不要将该封装与 SMD 混淆：SMD 是 surface-mount device 的缩写，泛指任何表面贴装（surface-mount）元件。也不要与同名的射频连接器类型混淆。

## 尺寸

下面是 SMA（DO-214AC）元件封装的尺寸。

<Image src={import('./_assets/package-do-214ac-2d-dimensions.png')} width="500px">DO-214AC 元件封装的尺寸。</Image>

引脚间距为 6.8mm（焊盘中心到焊盘中心）。
