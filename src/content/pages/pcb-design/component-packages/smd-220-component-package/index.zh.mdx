`SMD-220` 是 `TO-263` 元件封装的同义名称（因为 `TO-263` 被认为是 `TO-220` 封装的表面贴装（surface-mount）等效封装）。更多信息见 [TO-263 元件封装页面](/pcb-design/component-packages/to-263-component-package)。
