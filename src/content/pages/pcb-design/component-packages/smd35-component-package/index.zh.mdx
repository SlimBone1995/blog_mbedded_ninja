SMD35 是一款 2 引脚 SMD 封装，仅被 Seti 用于其深紫外（Deep UV）LED 系列。

由于引脚沿封装侧面向上延伸一小段距离，因此可以手工焊接。

热阻：在不考虑特殊 PCB 封装设计的情况下，该封装可耗散的最大功率为 200mW。

尺寸：

* WxLxH = 3.50x3.50x0.80mm
* 焊盘面积 = 12.25mm2（3.50x3.50mm）
