BGA（Ball Grid Array，球栅阵列）是一类高密度表面贴装（surface-mount）元件封装，引脚数可从 4 个到数千个。常见间距为 0.5mm、0.8mm 和 1.0mm。BGA 封装用于把元件做得非常小，或容纳大量引脚。现代大型 FPGA 和 CPU 有数千个焊球！

BGA 通常需要使用[回流炉](/pcb-design/soldering/)、红外加热器或热风返修台进行焊接。技术高超的焊接人员可以在封装倒置时采用“死虫”原型制作法，把极细的导线焊到每个焊球上，但不要认为这是一种可靠或快速的方法！由于焊点隐藏在封装下方，通常需要用 [X 射线检测](/electronics/manufacturing/x-ray-inspection/)来确认所有焊球都已正确焊接到焊盘上（电气测试可以发现开路和短路，外侧几排可以通过光学检测从侧面观察，但只有 X 射线能让你看到每一个焊点）。有关 PCB 返修的更多信息，参见 [PCB 返修指南](/pcb-design/the-pcb-rework-guide/)。

回流焊过程中，熔融焊料的表面张力会把封装拉向焊盘并对齐，因此 BGA 对小的贴装误差相当宽容。

常见用途包括：

- 微控制器
- [FPGA](/electronics/components/fpgas/)
- 高密度 SMD IC
- CPU
- GPU
- 存储器

## 相似封装

- [WLCSP](/pcb-design/component-packages/wlcsp-component-package/)
- [LGA](/pcb-design/component-packages/lga-component-package/)：类似 BGA，但底面是扁平焊盘而不是焊球。

## 焊球布局

特定 BGA 封装不一定具有完整的焊球网格。BGA 封装还有_直排_和_交错_两种焊球布局。

## 焊球编号

BGA 焊球由行字母和列数字标识，例如 A1、C3、D11。焊球 A1 位于封装上引脚 1 标记所指的角落。按照 JEDEC 惯例，字母 I、O、Q、S、X 和 Z 会被跳过，因为它们容易与数字或其他字母混淆。行数超过字母数的封装继续使用双字母（AA、AB、……）。

## BGA 焊盘直径

BGA 封装焊盘的直径可通过以下三种方法之一确定：

- 最大实体条件（MMC）
- 最小实体条件（LMC）
- 按标称焊球直径的百分比缩减（例如 20%）

## 阻焊层注意事项

在 PCB 上定义 BGA 焊盘可焊接区域有两种方式：

- **SMD**：阻焊限定（soldermask defined）。铜焊盘大于阻焊开窗，因此阻焊层覆盖铜箔边缘并限定可焊接区域。
- **NSMD**：非阻焊限定（non-solder mask defined）。阻焊开窗大于铜焊盘，因此由铜箔本身限定可焊接区域。

对于 BGA，通常首选 NSMD 焊盘。铜箔尺寸受蚀刻工艺控制，比阻焊层受其对位精度控制更严格，而且 NSMD 焊盘避免了阻焊层覆盖焊盘处形成的应力集中点。[^ti-an-1112-dsbga-wafer-level-chip-scale-package] 当焊盘内放置过孔时，也应使用 NSMD 焊盘。[^ti-an-1112-dsbga-wafer-level-chip-scale-package]

## 扇出

将 BGA 内部焊球的信号引出布线称为_扇出_。对于较粗的间距（例如 0.8mm 及以上），常见做法是_狗骨_扇出，即用一小段走线把每个焊盘连接到放置在四个焊球间隙中的过孔。对于更细的间距，没有足够空间这样做，改用_焊盘内过孔_（通常配合[微过孔](/pcb-design/pads-vias-holes/)），即把过孔直接放在 BGA 焊盘内。

## 变体

- CABGA（Chip Array BGA）
- CTBGA（Thin Chip Array BGA）
- DSBGA（Die-Size BGA）：由 Texas Instruments 使用。JEDEC 标准 MO-207。详见下文。
- FBGA（Fine-pitch BGA）：许多制造商还分配自己的封装代码，例如 Xilinx FGG484 是 484 焊球的无铅细间距 BGA。
- FCBGA（Flip-Chip BGA）：裸片翻转并直接键合到封装基板上。常用于 CPU、GPU、FPGA 和 TI 毫米波雷达 IC 等高性能 IC。
- X-DSBGA（Very thin die-size BGA）。JEDEC 标准 MO-211-C。
- xDSB（Square and rectangular die-size BGA）。JEDEC 标准 MO-207N。

### DSBGA

DSBGA（Die-Size BGA）是 Texas Instruments 对其裸片尺寸与封装尺寸相同的 BGA 封装系列的命名。它们也称为晶圆级芯片尺寸封装（Wafer-Level Chip Scale Package，WLCSP）。截至 2019 年 12 月，它们提供 0.30、0.35、0.40 和 0.50mm 间距。[^ti-an-1112-dsbga-wafer-level-chip-scale-package]
