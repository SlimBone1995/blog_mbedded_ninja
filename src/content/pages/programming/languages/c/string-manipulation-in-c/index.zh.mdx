本页教你如何在 C 编程语言中处理字符串（string）。如果你习惯了 Python 或 Javascript 等高级语言，很快就会发现 C 缺少一些“好用”的字符串操作特性，例如用 `+` 进行字符串拼接（如 `str1 + str2`）、没有方便的 `.length()` 属性（虽然有 `strlen()` 函数），也没有内置的正则引擎。它甚至没有真正的字符串类型概念，只有“[指向 char 的指针](/programming/languages/c/pointers/)”（`char*`）（有人会说，从实际用途看这就是字符串类型）。

## C 中的字符串是什么？

C 中的字符串可以用指向 char 的指针 `char* myStr` 表示，也可以用 [char 数组](/programming/languages/c/arrays/) `char myStr[10]` 表示。内存中存放的是一系列字节大小的 ASCII 编码字符，并以空字符（`'\0'` 或 `0x00`）结尾。

假设我们要存储字符串 "Hello"。可以写 `char* myStr = "Hello";`。如果编译器决定把它放在内存地址 `0x01`（我避开了 `0x00`，因为它无效——那是空指针），那么内存看起来如下：

```text
Memory address | Value | ASCII
0x00           |       |
0x01           | 0x48  | H
0x02           | 0x65  | e
0x03           | 0x6C  | l
0x04           | 0x6C  | l
0x05           | 0x6F  | o
0x06           | 0x00  | \0
0x07           |       |
```

但这还不是全部：上面的内存只用于创建字面量 `"Hello"`。同时还会创建变量 `myStr`，它指向该字符串的第一个字符。假设编译器决定把它放在内存地址 `0x08`，那么内存看起来如下（为便于说明做了简化——在真实的 64 位架构上，指针本身会占用 8 个字节）。

```text
Memory address | Value | ASCII
0x00           |       |
0x01           | 0x48  | H
0x02           | 0x65  | e
0x03           | 0x6C  | l
0x04           | 0x6C  | l
0x05           | 0x6F  | o
0x06           | 0x00  | \0
0x07           |       |
0x08           | 0x01  |      // This is myStr
```

无论何时把字符串变量 `myStr` 传给函数，传入的都是这个 `0x01` 值。字符串函数知道其类型（指向 char 的指针），因此在对字符串进行操作时，会逐字节递增内存，直到遇到空字符。

C 与许多其他语言的一个不同之处在于，它选择用 null 来确定字符串的结尾，而不是在字符数组开头保留一些字节来存放长度。要获取字符串长度，必须逐字节遍历直到找到 `0x00`，这正是 `strlen()` 所做的（详见下文）。

## 创建字符串的不同方式

在 C 中，只要你在双引号里写任何内容（如 `"abc"`），就是在创建所谓的字符串字面量。你可以把字符串字面量赋给指向 char 的指针，如下所示：

```c
char* myStr = "abc"; // This is a string literal
```

也可以把字符串字面量赋给 char 数组，如下所示：

```c
char myStr2[] = "abc"; // Creating a string literal and assigning it to any array
                       // (the size is inferred from the right-hand side of the equation)
```

这两种方式大体等价，但必须记住：`myStr2` 是一个大小在编译期已知的数组，而 `myStr` 只是一个指向 char 的指针。因此，`sizeof()` 的行为会有所不同。

在面向 64 位架构编译时，`sizeof(myStr)` 返回 8，即指针 `myStr` 所需的字节数（该指针指向 `"abc"` 中 `a` 的内存地址）；而 `sizeof(myStr2)` 返回 4，即数组 `myStr2` 的字节数，它由 `['a', 'b', 'c', '\0']` 组成。这个差异早晚会让你栽跟头，务必注意。

<Aside type="tip">
大多数时候你会把字符串传入函数；如果使用 `char myStr[]` 风格的语法，编译器根本不知道 char 数组有多大（你可能从一个函数传入 `char str[10]`，从另一个函数传入 `char str[20]`）。该数组会“退化”为与 `char* myStr` 相同的东西，sizeof 会返回指针的大小（除非该函数被设计为只接受特定大小的字符串，例如 `char myStr[10]`，但那是非常奇怪的用法）。

因此，你不能用 `sizeof()` 来计算字符串有多大。你有两个选择：用 `strlen()` 获取字符串中的字符数；或者，如果你不仅关心字符串中有多少有效字符、还关心数组有多大，**就必须同时把大小传入函数**。在 C 应用中传入字符串数组的大小是非常常见的做法（对任何数组都是如此，不限于字符串），一段时间后就会成为习惯。
</Aside>


你也可以创建一个指定大小的空字符串：

```c
char myEmptyString[50];
```

<Aside type="caution">
`char myEmptyString[50];` 在函数内部不会初始化任何字节（但如果在函数外声明，则会被零初始化，因为它具有静态存储期，会被放入 [.bss 段](/programming/languages/c/bss-section/)）。这意味着它不是一个定义良好的字符串，其中是否包含空字符取决于内存当时的内容。例如：

```c
int main() {
    char myEmptyString[50];
    printf("%s", myEmptyString); // BAD! Undefined behaviour. Could get lucky and print nothing, could print garbage, 
                                 // or could get really unlucky and print from memory until it reaches the end of memory
                                 // (it will keep printing until it finds a 0x00 in memory).
}
```

你必须做的是初始化字符串。最简单的方法是使用 `= {0}`：

```c
int main() {
    char myEmptyString[50] = {0};
    printf("%s", myEmptyString); // Better! Will print nothing, but at least you have defined behaviour.
}
```

另一种选择是只把第一个字节设为空字符，这其实就是让它成为有效字符串所需的全部操作。不过，我仍然不喜欢这种方法，因为它更难诊断问题（如果你把一切都初始化为 0，就可以确定：如果字符串中出现了奇怪的值，那一定是代码某处有 bug）。

```c
int main() {
    char myEmptyString[50];
    myEmptyString[0] = '\0'; // All you really need to set is the first byte to 0x00
    printf("%s", myEmptyString); // Also good!
}
```

</Aside>

## 字符与字符串

在 C 中，`'A'` 和 `"A"` 是完全不同的类型（不像在 Javascript 中，把 `"` 换成 `'` 什么都不会变）。`'A'` 是单个字符，而 `"A"` 是字符串字面量（即字符数组）。你不能这样写：

```c
char myChar = "A"; // This is wrong!
char* myString = 'A'; // This is also wrong!
```

你必须这样写：

```c
char myChar = 'A'; // This is correct!
char* myString = "A"; // This is also correct!
```

因此，要设置字符串中的单个字符，可以使用 `'` 表示法：

```c
char myString[] = "Hello";
myString[0] = 'h'; // Sets the first character to 'h', now it's "hello"
```

<Aside type="caution">
注意上面使用的是 `char myString[]` 而不是 `char* myString`。通过指向字符串字面量的 `char*` 修改字符串属于未定义行为——字符串字面量通常放在只读内存中，写入它通常会导致程序崩溃。把字面量赋给数组则会把这些字符复制到可写内存中。
</Aside>

`char` 字面量末尾不会附加空字符，它只是一个字节。

## ASCII 字符

### 空字符

空字符（用 `'\0'` 或 `0x00` 表示，有时称为 `NUL`——不要与 `NULL` 混淆，后者是空*指针*常量）用于终止字符串。大多数基于字符串的命令会自动在字符串末尾插入空字符，而内存操作命令不会。必须特别注意，确保为字符串预留的内存能够容纳空字符（以字节计，即 ASCII 字符数 + 1）。

### 回车与换行

这两个字符用于开始新的一行文本。如果按字面理解其名称，回车会把光标移回行首，换行则把光标下移一行。这些字符让人想起打字机时代。

在 Linux 风格系统中，只使用换行字符来开始新的一行文本。在 Windows 中，回车和换行字符都会使用。对于嵌入式系统，我见过两种偏好都有（可能取决于作者使用的开发操作系统！）。大多数终端程序两种方式都支持。回车通过 `\r` 插入代码，换行通过 `\n`。在 Windows 中，标准顺序是先写回车，再写换行 `\r\n`。

<Aside type="tip">
Windows 风格的 `\r\n` 通常也能在大多数 Linux 风格系统上工作，只要 `\r` 被忽略即可。
</Aside>

在许多其他编程语言中，你不必手动添加行尾，因为 `print` 风格的函数会自动完成（默认如此——如果不需要这种行为，通常也可以禁用）。C++ 介于两者之间，标准做法是使用 `std::endl`。

### 大小写切换

在代码中，通过翻转第 5 位可以轻松切换 ASCII 字符的大小写。这可以通过与空格字符进行异或来实现，如下所示：

```c    
printf("%c", 'A' ^ ' ');
// a

printf("%c", 'a' ^ ' ');
// A
```

## 获取长度

使用 `string.h` 提供的 `strlen()` 函数：

```c
#include <stdio.h>
#include <string.h>

int main() {
  char my_string[] = "Hello"; 
  printf("%zu\n", strlen(my_string));
  return 0;
}
// Prints "5"
```

## 复制

`strcpy()` 是标准库函数（来自 `string.h`），用于把一个 C 字符串的内容复制到另一个字符串。它把源字符串的字符（包括空字符）复制到目标缓冲区，直到并包括空字符。你需要自行确保目标缓冲区足够大——如果不够，就会发生缓冲区溢出。

```c
#include <stdio.h>
#include <string.h>

int main() {
    char src[] = "Hello";
    char dest[10]; // Must be large enough to hold "Hello" plus the null character
    strcpy(dest, src);
    printf("%s\n", dest); // Prints "Hello"
    return 0;
}
```

更安全的替代方案是 `strncpy(dest, src, n)`，它写入目标的字节数永远不会超过 `n`。但要注意它的一个大坑：如果 `src` 放不下，`dest` **不会**以空字符结尾，因此通常的做法是之后手动把最后一个字节设为 `'\0'`：

```c
char dest[10];
strncpy(dest, src, sizeof(dest));
dest[sizeof(dest) - 1] = '\0'; // Guarantee null termination
```

<Aside type="note">
你知道吗：下面这段短代码……

```c    
while (*p++ = *q++);
```

等价于标准库函数 `strcpy(p, q)`！
</Aside>



## 拼接

与许多高级语言不同，你不能像这样直接拼接 C “字符串”：`my_string_1 + my_string_2`（记住，它们只是字符数组！）。你必须使用 `strcat()` 函数（来自 `string.h`），它把源字符串的副本追加到目标字符串末尾。与 `strcpy()` 一样，你需要自行确保目标缓冲区足够大，以容纳拼接后的结果：

```c
#include <stdio.h>
#include <string.h>

int main() {
    char dest[20] = "Hello"; // Must be large enough to hold "Hello World" plus the null character
    strcat(dest, " World");
    printf("%s\n", dest); // Prints "Hello World"
    return 0;
}
```


## printf（及其变体）

`printf()` 及其变体（如 `sprintf()`）是最常见的“某物转字符串”函数之一。它们可用于把有符号整数、无符号整数、float、double 和其他类型转换为字符串。它们也可用于打印已格式化的字符串，和/或将现有字符串拼接在一起。它们还支持格式化选项，可让你控制数字的显示方式（如小数位数、填充、以十六进制显示等）。

<Aside type="note">
`printf` 代表“print formatted”（格式化打印）。[^wikipedia-printf]
</Aside>

### printf()

`printf()` 是最常用的字符串输出函数。它是一个[可变参数函数](/programming/languages/c/variadic-functions/)（接受可变数量的参数；注意，这与函数重载不同，C 不支持函数重载）。

在 Linux、MacOS 和 Windows 等大多数主流操作系统上，调用 `printf()` 会把格式化字符串发送到终端（如果应用是从终端启动的）。在嵌入式系统上没有“标准输出”，但越来越多的现代嵌入式系统会把 `printf()` 路由到默认调试串口。

如果你想用 `printf()` 打印一个已经格式化好的字符串（没有要插入的额外参数），不要使用 `printf(msg)` 这种语法。而应使用 `printf("%s", msg)` 这种格式。

```c    
char* msg = "Example message";

// This is the incorrect and unsafe way of printing
// an already formulated string, and the compiler
// should give you a warning.
printf(msg);

// The correct way of printing an already-formulated
// string
printf("%s", msg);
```

`printf()` 函数接受格式说明符（format specifier），用来告诉函数你希望数字如何显示。

大多数 C 编译器安装都包含用于字符串操作的标准 C 库。常见的是 `stdio.h`，通常用 `#include <stdio.h>` 语法包含到 C 文件中。该库包含字符串复制、拼接、字符串构建等许多功能。它们大多依赖以空字符结尾的字符串才能正常工作。下面列出一些最常用的函数。

<Aside type="caution">
`printf()` 及其同类函数可能给处理器带来很大负担，并可能打乱代码的实时截止时间（这对嵌入式编程尤其重要）。最好让 `printf()` 调用远离高优先级中断和控制循环，而把它们放在可被抢占的后台任务中（被中断抢占，或在运行 RTOS 时被更高优先级的线程抢占）。

例如，RTOS/框架 [Zephyr](/programming/operating-systems/zephyr/) 默认使用延迟日志，即保存格式字符串和变量，并传给低优先级的日志线程处理。
</Aside>

### 格式说明符

`printf()` 有许多可用的格式说明符，可改变文本的格式。格式说明符位于 `%` 符号与上文提到的转换说明符之间。它们是可选的，但如果使用，必须按正确顺序添加。

我遇到过不支持字符串填充（如 `%5s` 或 `%-6s`）的嵌入式 `printf()` 实现，包括 [PSoC 5](/programming/microcontrollers/psoc/) 所用的版本。

### 可移植的 size_t 打印

为可移植性，打印 `size_t` 类型的值（如 `sizeof()` 返回的数字）时可以使用 `z` 格式说明符。

```c    
// Portable way of printing a size_t number,
// using the 'z' modifier.
// (which sizeof() returns)
printf("Size of int = %zu.\r\n", sizeof(int));
```

这是在 ISO C99 中引入的。`Z`（大写 `z`）是在该标准增补之前就存在的 GNU 扩展，不应在新代码中使用。

### sprintf()/snprintf()

`sprintf()` 是 `printf()` 的变体，它把格式化字符串写入缓冲区（你提供指向它的指针），而不是写入标准输出。它适合构建你不希望送往标准输出、或希望稍后再发送到标准输出的字符串。

`snprintf()` 是 `sprintf()` 的更安全版本（我建议始终使用更安全的“n”风格 `printf()` 函数），它多接受一个指定缓冲区大小的参数。这可防止缓冲区溢出。如果缓冲区不足以容纳格式化字符串，字符串会被截断以适应缓冲区。

`snprintf()` 示例（注意使用 `sizeof()` 把缓冲区大小传入函数；如果格式化字符串大于缓冲区，这可防止越界）：

```c
char stringBuff[100] = {0}; // Create buffer for snprintf() to write to. Init. to 0 is not strictly needed here.

snprintf(stringBuff, sizeof(stringBuff), "Hello %s", "World"); // Write formatted string to buffer
// stringBuff now contains "Hello World\0" at the start of it
```

#### Keil C51 编译器

在 Keil C51 编译器中，`b` 或 `B` 长度说明符用于告诉 `sprintf` 该数字是 8 位的。如果不使用它，存储在 `uint8_t` 或 `char` 数据类型中的 8 位数字将无法正确打印。使用 GCC 时无需使用 `b/B` 说明符。

```c
// Print a float to 2 decimal places
snprintf(txBuffer, sizeof(txBuffer), "Float to 2dp: %.2f", float1);

// Print a 8-bit number in the Keil C51 compiler, using the length specifier 'b' ('B' can be used also)
uint8_t eightBitNum = 23;
sprintf(txBuffer, "This is an 8-bit number: %bu", eightBitNum);
```

## itoa()

**`itoa()` 是 C 语言中广泛实现但非标准的扩展**。尽管实现广泛，它并非无处不在：Linux 上的 GCC 就不支持它（而 GCC 在 C 编译器领域占有巨大份额）。尽管 C 编程标准未规定它，它却令人困惑地通过 `stdlib.h` 提供，因为它补充了该头文件中已有的函数。[^wikibooks-itoa] 它也不属于 C++ 标准。[^cplusplus-itoa]

`itoa()` 通常定义如下：

```c
char* itoa(int value, char* str, int base);
```

进制通常限于八进制（8）、十进制（10）或十六进制（16）。[^ibm-zos-docs-itoa]

用法：

```c
#include <stdio.h>
#include <stdlib.h>
int main() {
    int number = 436;
    char buffer[10];
    itoa(number, buffer, 10);
    printf("%s", buffer); // Prints 436
}
```

如果缓冲区不够大，无法容纳传入整数的字符串表示，`itoa()` 可能导致未定义行为。如果你传给 `itoa()` 的整数范围有限，可以很容易地确定缓冲区应有多大。如果可能是任意整数，则需要一个能容纳 `INT_MIN`（以及末尾 `NULL`）的缓冲区。`itoa()` 的更安全替代方案（并且可移植）是使用 `snprintf()`。

## 字符串转数字函数

`printf()` 及其同类函数把东西转换为字符串。但反过来呢？C 标准库提供了多种把字符串转换为数字的函数。下面列出最常见的几个。

### atof()

`atof()` 是一种历史悠久的把字符串转换为双精度浮点数的方法（是的，尽管函数名里有 `f`，它实际返回的是 `double`）。

`atof()` 的一个显著缺点是，你无法区分输入文本 `"0.0"` 与没有有效数字可转换的情况。这是因为如果输入字符串中找不到有效的浮点数，`atof()` 会返回 `0.0`。例如，它无法区分 `"0.0"` 和 `"poos"`：

```c
double result;
result = atof("0.0"); // result = 0.0
result = atof("poos"); // result = 0.0
```

另一个问题是，`atof()` 无法让你检查输入字符串是否只是一个有效数字，且数字后面没有夹杂垃圾字符。这是因为它逐字符遍历字符串，一旦遇到无效字符就停止处理。

有一个更好的替代方案 `strtod()`，它修复了上述两个问题。

### strtod()

它代表 string-to-double（字符串转双精度）。这是比 `atof()` 更安全的字符串转 double 方法。下面的代码示例展示如何用 `strtod()` 把字符串转换为 double，以及如何检查输入字符串是否包含有效数字。较新的 C/C++ 版本还提供 `strtof()`，功能相同但返回 `float` 而非 `double`。

```c
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>

/// Converts a string to a double. Returns true on success, false if the
/// input did not start with a valid number. The converted number is
/// written to output.
bool ConvertStringToDouble(const char* input, double* output) {
    char* numEnd;

    // Do the conversion
    *output = strtod(input, &numEnd);

    // Bounds checking
    if (numEnd == input) {
        printf("Error: Input to strtod was not a valid number.\r\n");
        return false;
    }

    return true;
}
```

### strtol()

`strtol()` 的行为与 `strtod()` 非常相似，只是把字符串解析为 `long int` 而不是 `double`。

## 字符串解码/编码

`strtok()` 是一个有用的标准字符串解码函数。它把字符串拆分为一组子字符串，拆分位置由传入函数的特定分隔符决定。它在解码基于 ASCII（即人类可读）的通信协议时很有用，例如命令行接口或 [NMEA 协议](/electronics/communication-protocols/nmea-protocol/)。更多内容请参阅 [C++ Reference 网站](http://www.cplusplus.com/reference/cstring/strtok/)。

`getopt()` 是一个标准函数，用于查找传入 `main()` 的命令行参数（以字符串数组形式）（深入指南参见[处理命令行输入页面](/programming/languages/c/processing-command-line-input/)）。它包含在 [GCC glibc 库](http://www.gnu.org/software/libc/)中。相关文件也可在[此处](/misc/string-manipulation-in-c/getopt.zip)本地下载（取自 GCC gLibC v2.17）。

## 把版本字符串转换为数字

有时你可能想把 `v1.2.3` 形式的版本字符串转换为单独的 major、minor 和 patch 数字。

下面的 C 代码展示了一个函数 `VersionStringToNumbers()` 如何做到这一点，并附带一个示例 `main()`，它对该函数运行一些测试，以确保能正确处理有效和无效输入。

这里使用 `strtol()` 而不是 `atoi()`，因为 `atoi()` 无法区分无效输入和 `"0"`（即它无法区分 `"0"` 和 `"poop"`！）。此外，返回的 `end` 指针用于在字符串中递增、检查最后一个数字后是否紧跟 `.`，并确定从何处开始处理下一个整数。

```c
#include <assert.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

/**
 * @brief Converts a version string in the form "1.2.3" into numbers.
 *
 * @param[in] version A null-terminated string of the form "1.2.3". The
 *    major and minor numbers must be in the range [0, 255]. The patch
 *    number must be in the range [0, 65535]. There must not be a "v" at
 *    the start.
 * @param[out] major The converted major version number.
 * @param[out] minor The converted minor version number.
 * @param[out] patch The converted patch version number.
 * @return Returns 0 on success, or -1 on failure.
 */
int8_t VersionStringToNumbers(char const *const versionString,
                                                            uint8_t *const major, uint8_t *const minor,
                                                            uint16_t *const patch) {

    char const *offset = versionString;
    char *end;

    // MAJOR NUMBER
    // Don't use atoi(), can't detect difference between "0" and "poop"!
    int majorLocal = strtol(offset, &end, 10);
    if (end == offset) {
        return -1;
    }
    if (majorLocal < 0 || majorLocal > 255) {
        return -1;
    }
    offset = end;
    // Make sure a "." is immediately after the major version number
    if (*offset != '.') {
        return -1;
    }

    // MINOR NUMBER
    offset += 1; // Increment offset to point to first char after found "."
    int minorLocal = strtol(offset, &end, 10);
    if (end == offset) {
        return -1;
    }
    if (minorLocal < 0 || minorLocal > 255) {
        return -1;
    }
    offset = end;
    if (*offset != '.') {
        return -1;
    }

    // BUILD NUMBER
    offset += 1; // Increment offset to point to first char after found "."
    long patchLocal = strtol(offset, &end, 10);
    if (end == offset) {
        return -1;
    }
    if (patchLocal < 0 || patchLocal > 65535) {
        return -1;
    }
    offset = end;
    // Make sure the string ends after the build number
    if (*offset != '\0') {
        return -1;
    }

    // Save to outputs, we can safely cast because we performed range checks above
    *major = (uint8_t)majorLocal;
    *minor = (uint8_t)minorLocal;
    *patch = (uint16_t)patchLocal;

    return 0;
}

int main(void) {
    uint8_t major, minor;
    uint16_t patch;

    printf("Running VersionStringToNumbers() tests...\n");
    int8_t rc = VersionStringToNumbers("1.2.3", &major, &minor, &patch);
    assert(rc == 0);
    assert(major == 1);
    assert(minor == 2);
    assert(patch == 3);

    rc = VersionStringToNumbers("56.234.9876", &major, &minor, &patch);
    assert(rc == 0);
    assert(major == 56);
    assert(minor == 234);
    assert(patch == 9876);

    rc = VersionStringToNumbers("256.1.2", &major, &minor, &patch);
    assert(rc != 0);

    rc = VersionStringToNumbers("", &major, &minor, &patch);
    assert(rc != 0);

    rc = VersionStringToNumbers("1.2.", &major, &minor, &patch);
    assert(rc != 0);

    rc = VersionStringToNumbers("1a.2.3", &major, &minor, &patch);
    assert(rc != 0);

    rc = VersionStringToNumbers("1.2.3a", &major, &minor, &patch);
    assert(rc != 0);

    rc = VersionStringToNumbers("..", &major, &minor, &patch);
    assert(rc != 0);

    printf("Tests complete.\n");
    return 0;
}
```
