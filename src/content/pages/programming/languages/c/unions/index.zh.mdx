**联合体（union）用于创建可以用不同数据类型访问的数据结构。** 下面是一个联合体的示例。它定义了一个 result_t 类型，既可以按 32 位值读写，也可以按 8 位错误码读写。

```c    
typedef union {
    uint32_t value;
    uint8_t error;
} result_t;
```

当函数参数具有多种用途时，联合体很有用。

联合体的目的是通过在不同时间使用同一内存区域存储不同对象来节省内存。联合体**不是**用于类型转换的。
