FreeRTOS 是一个流行的、适用于嵌入式系统的免费实时操作系统（real-time operating system）。它针对特定处理器架构/编译器组合提供了数百个预配置移植。我不会详细讲解 FreeRTOS API，因为 [FreeRTOS 网站](http://www.freertos.org/) 上已有极其完善的文档。下面是一份快速参考指南。

## 获取代码

你可以从 [http://sourceforge.net/projects/freertos/files/](http://sourceforge.net/projects/freertos/files/) 下载，也可以使用以下命令检出官方 SVN 仓库（我推荐这种方式）：

```sh
# Checks out the main branch
svn co https://freertos.svn.sourceforge.net/svnroot/freertos/trunk freertos

## Or if you want to get all branches, omit the /trunk part and use
svn co https://freertos.svn.sourceforge.net/svnroot/freertos freertos
```

## 减少 FreeRTOS 占用 RAM 的技巧

* 减少可用任务优先级的数量（在 FreeRTOSConfig.h 中设置，即 configMAX_PRIORITIES 和 configMAX_CO_ROUTINE_PRIORITIES）
* 减小每个任务/协程的栈大小。
* 仅使用协程（不使用任务）。不过这样做有一些缺点……

## 内存指南

使用 FreeRTOS 时需要额外考虑内存问题！你必须了解并理解堆和栈。

队列存储在堆上，信号量也是如此。可以通过调用函数 xPortGetFreeHeapSize(); 查看剩余堆大小。

## Fat 文件系统

从 v7.5.0 起，FreeRTOS 支持由 HCC Embedded 提供的 Fat SL 嵌入式文件系统库。它支持一系列标准文件操作（例如 `f_open()`、`f_write()`）。

## 错误检查

FreeRTOS 提供宏 `configASSERT()`。如果传给 configASSERT() 的参数为零，就会触发断言。它的行为类似于标准 C 的 `assert()` 宏。用户需要为 configASSERT() 提供实际实现，FreeRTOS 并未定义它，只是在整个代码中使用它。下面给出一个定义示例（取自 FreeRTOS 网站）：

```c    
/* Define configASSERT() to call vAssertCalled() if the assertion fails.  The assertion has failed if the value of the parameter passed into configASSERT() equals zero. */
#define configASSERT( ( x ) )     if( ( x ) == 0 ) vAssertCalled( __FILE__, __LINE__ )
```

建议你在代码中使用它，以进行一次性及持续性错误检查！
